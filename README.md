# -magic-ball-8
Магический шар 8 (Шар судьбы)
Консольная игра на Python, которая имитирует магический шар, предсказывающий будущее.

## 🕹️ Как это работает
1. Программа приветствует пользователя и спрашивает его имя.
2. Пользователь задает любой вопрос.
3. Шар случайным образом выбирает один из 20 возможных ответов (положительные, нейтральные, отрицательные).
4. Можно задавать вопросы до тех пор, пока пользователь не решит выйти.
